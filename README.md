# motor-vibration-diagnostic-tool

This project develops a portable vibration-monitoring system for electric-motor and rotating-machine diagnostics. An embedded controller will collect acceleration data from a sensor mounted to a motor or test fixture, while Python-based analysis will visualize vibration behavior in both the time and frequency domains.

The system will establish healthy operating baselines and compare them against controlled test conditions, including imbalance, loose mounting, and mechanical rubbing. The project emphasizes sensor integration, embedded data acquisition, signal processing, repeatable testing, and condition monitoring.
